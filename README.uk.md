# Vocal Pitch Trainer

Інструмент для тренування слуху та вокальної інтонації, що працює прямо в браузері. Почуйте ноту, проспівайте її у відповідь і подивіться, наскільки точно ви влучили — виміряно в центах відносно цільової висоти звуку.

Створено **N. Scherbak**.

Без етапу збірки, без залежностей, без сервера. Один HTML-файл, який працює повністю у вашому браузері за допомогою Web Audio API. Нічого не завантажується на сервер; звук з мікрофона ніколи не залишає ваш пристрій.

## Режими

Інструмент побудований у вигляді кількох чітких кроків:

1. **Ноти** — оберіть, що ви будете співати, за допомогою одного з чотирьох режимів (нижче).
2. **Налаштування** (згорнуті за замовчуванням) — звук, темп відтворення, режим оцінювання, час співу, середовище мікрофона та ваш голосовий діапазон. Типові значення підходять більшості людей; згорнутий рядок показує однорядкове резюме.
3. **Відтворити й співати** — **«Відтворити ноту»** відтворює кожну ноту окремо, по одній; **«Відтворити фразу»** відтворює всю послідовність, а потім ви співаєте її у відповідь.
4. **Результати** — очікуване проти заспіваного для кожної ноти, а також загальне резюме після завершення всієї вправи.

### Ноти: чотири режими

- **Вручну** — обирайте ноти по одній за допомогою випадного списку та кнопки «Додати» (до 9 нот), перетягуйте, щоб змінити порядок, × щоб видалити.
- **Гами** — оберіть тип гами (мажор або натуральний мінор), тональність (усі 12, з правильним написанням — див. нижче), початкову октаву, кількість октав діапазону та напрямок (вгору / вниз / вгору і вниз). Автоматично генерує повну гаму.
- **Арпеджіо** — оберіть тип акорду (мажорне/мінорне тризвуччя, мажорний/домінантний/мінорний септакорд), тональність, октаву, діапазон і напрямок. Ноти акорду (3 або 4 ноти) визначаються автоматично — не потрібно рахувати їх самостійно.
- **Секвенції** — стандартні вокальні розспівувальні патерни, побудовані на ступенях гами: висхідний рух із 3 нот, оберт із 3 нот, висхідний рух із 4 нот, терції та оберт із 5 нот. Оберіть тип гами, тональність і початкову октаву — про решту подбає патерн.

Кнопка **«Очистити»** присутня в кожному режимі, оскільки ноти — це одна спільна послідовність незалежно від того, який режим її створив — не потрібно перемикатися назад на «Вручну», щоб просто скинути.

### Правильне написання тональностей

Кожна тональність записується правильно у своєму контексті — мажорна гама фа читається як F-G-A-**B♭**-C-D-E-F, а не F-G-A-**A♯**-C-D-E-F. Два слоти «чорних клавіш», де мажор і мінор традиційно розходяться в написанні (C♯/D♭ та G♯/A♭), автоматично розв'язуються відповідно до того, яке написання є стандартним для обраного типу гами.

### Раунди

Згенерована вправа, довша за кілька нот, розбивається на **раунди** приблизно по 4 ноти кожен, тож вам ніколи не доведеться співати 15 нот на одному диханні. Кожен раунд практикується й оцінюється окремо; індикатор раунду («Раунд 2 з 4 · D3–D5») показує ваше місце та діапазон усієї вправи. Кнопка **«Наступний раунд →»** з'являється після оцінювання раунду; коли всі раунди завершено, з'являється також кнопка **«Підвищити на півтон ↑»** — стандартний вокальний прийом розспівування, який повторює ту саму вправу, транспоновану на півтон вище, замість того, щоб змушувати вас щоразу заново обирати тональність.

### Вгору і вниз

**«Відтворити вгору і вниз»** (поруч із фішками нот, для 2+ нот) віддзеркалює обране на льоту — C-E-G відтворюється як C-E-G-E-C, верхня нота лише один раз, без повторення — без зміни самих фішок. Це той самий механізм незалежно від того, звідки походять ноти — «Вручну», «Гами» чи «Арпеджіо» (патерни «Секвенцій» уже є завершеними формами і не використовують цю функцію).

## Початок роботи

Інструмент відкривається без обраних нот — побудуйте свою фразу з нуля (додайте ноти вручну або згенеруйте через «Гами», «Арпеджіо» чи «Секвенції»). Кнопка «Відтворити» залишається неактивною, доки не обрано хоча б одну ноту.

Коли заспівану ноту неможливо оцінити, зворотний зв'язок розрізняє два випадки: **звук не виявлено** (нічого не надійшло з мікрофона) проти **нота занадто коротка** (звук був почутий, але не тримався достатньо довго, щоб його зчитати) — тож ви знаєте, чи співати гучніше, чи тримати довше.

## Профілі

Легка система нікнеймів — без входу в систему, без облікового запису, без сервера. Перемикач «Хто зараз практикується?» у шапці дозволяє кільком людям ділитися одним пристроєм, не змішуючи налаштування. Під час першого відвідування невелике вітальне вікно пропонує зберегти нікнейм (можна пропустити — ви завжди можете додати його пізніше через **«+ Новий»**). Усе зберігається в локальному сховищі вашого браузера, прив'язане до цього нікнейму, на цьому пристрої.

## Голосовий діапазон

У «Налаштуваннях» встановіть свій комфортний діапазон співу — або обравши ноти напряму, або за допомогою **«🎤 Визначити»**: короткого інструменту з покроковими підказками, який попросить вас проспівати найвищу комфортну ноту, потім найнижчу, кожну утримуючи щонайменше півсекунди, і дозволить перевірити чи скоригувати результат перед збереженням.

Діапазон є **лише порадою** — він ніколи нічого не блокує. Якщо згенерована вправа виходить за його межі, ви побачите коротке повідомлення (наприклад, «Ця вправа сягає F5, що на 4 півтони вище за ваш вказаний діапазон») і все одно зможете її практикувати або скоригувати свій діапазон.

Щойно діапазон встановлено, панелі «Гами»/«Арпеджіо»/«Секвенції» показують список **«Рекомендовано для вашого діапазону»** — топ-3 тональності, ранжовані за кількістю нот, які справді вписуються у ваш діапазон, наприклад «до мажор — 8/8» — а вибір тональності також автоматично підставляє найбільш відповідну октаву. Обидва варіанти — лише підказки; кожна тональність і октава залишаються повністю доступними для вибору.

## Підказки для початківців

- Під час співу **індикатор (метр)** є живим показником — не потрібно читати текст під час ноти, просто дивіться на стрілку. Вона світиться і розширюється, коли ви влучаєте в ноту, і фіксується на краю з підписом (наприклад, «≪ приблизно на два тони нижче»), якщо відхилення більше, ніж індикатор може показати.
- Після кожної ноти **картка результату** показує ціль, ноту, яку ви насправді заспівали (наприклад, `D3 +12¢`), і вердикт простою мовою — *«приблизно на півтора тона нижче»* замість необроблених центів. Жаргон не потрібен.
- Після завершення всієї вправи рядок резюме показує загальний підрахунок — *«3/4 нот у тон — деталі нижче»*.
- Розгортувана панель **«Вперше тут?»** пояснює ноти, півтони, тони, дієзи/бемолі та центи простою мовою.

Інформаційна панель поруч із кнопками відтворення описує кожен крок: анімована хвиля під час відтворення ноти, підказка **«Приготуйтеся»** зі спокійним відліком трьох крапок, дружня підказка **«Співайте!»** під час вашої черги, та резюме наприкінці.

## Зворотний зв'язок

Посилання **«надіслати відгук»** розташоване поруч із підписом автора. Воно відкриває невелику форму (необов'язкова електронна пошта + ваше повідомлення), яка передає дані у вашу власну поштову програму — нічого не надсилається кудись іще, і жодна адреса не зберігається на сторінці.

## Керування часом

**«Час співу для кожної ноти»** (використовується в режимі **«За таймером»** — зникає в режимі «Слідуй за мною») встановлює, скільки часу дається на спів кожної ноти:

- **Типовий** — адаптивний: 3 секунди для однієї ноти, 2 секунди на ноту, якщо їх дві або більше.
- **1 с / 2 с / 3 с** — фіксований час на ноту для кожної ноти в послідовності.

Таймер із крапками автоматично адаптується до загального вікна часу: останні 5 секунд показуються як 10 дрібних крапок (одна щопівсекунди), а все, що до того — як одна крапка на секунду, тож довгі фрази залишаються зрозумілими.

**Темп відтворення** (Типовий / Повільно / Середньо / Швидко) встановлює, як швидко застосунок відтворює вам еталонні ноти — «Повільно» це приблизно одна нота за секунду, аж до «Швидко» — три-чотири. Це впливає **лише на відтворення**; ваш час співу повністю визначається налаштуванням нижче, у режимі «За таймером».

## Як оцінюється спів

Два способи оцінити заспівану фразу:

- **«За таймером»** — класичний режим. Кожна нота очікується протягом свого підсвіченого слоту за фіксованим таймером (налаштування «Час співу для кожної ноти»). Передбачувано і добре підходить для суворої практики.
- **«Слідуй за мною»** — співайте фразу у власному темпі, а застосунок слідує за вами. Він записує весь дубль, знаходить ноти, які ви справді *утримували* (нота має утримуватися щонайменше **півсекунди**, щоб зарахуватися, тож випадковий прохід через правильну висоту не зараховується), і зіставляє їх по порядку з очікуваною послідовністю. Час більше не має значення — важливо лише, які ноти ви утримали і в якому порядку.

У режимі **«Слідуй за мною»** селектор «Час співу для кожної ноти» перетворюється на загальний часовий *бюджет* на ноту, а не на суворий слот, із мінімумом, що завжди залишає простір для утримання кожної ноти впродовж повної секунди. Якщо застосунок виявляє іншу кількість утриманих нот, ніж очікувалося, він повідомляє про це (наприклад, «виявлено 4 утримані ноти з 5»), що зазвичай означає, що дві ноти злилися разом або одна нота «затремтіла» на дві.

«Слідуй за мною» працює за евристикою і найкраще підходить для чіткого, свідомого співу з невеликою паузою між нотами; дуже плавні (легато) фрази або сильне вібрато можуть заплутати розділення нот. Цей режим орієнтований на початківців і аматорів співу, які хочуть природної практики, а не дисципліни таймера.

## Середовище запису

**«Тиха кімната»** (за замовчуванням) використовує необроблений сигнал вашого мікрофона, що найточніше зчитує висоту звуку. **«Шумна кімната»** вмикає придушення шуму браузером та автоматичне регулювання посилення — це зменшує фоновий шум під час запису вашого голосу, але може дещо вплинути на точність визначення висоти. Перемикання цієї опції повторно отримує доступ до мікрофона, оскільки налаштування застосовується під час запуску мікрофона.

## Примітки щодо мобільних пристроїв

Застосунок працює на телефонах, з кількома обмеженнями браузера, про які варто знати:

- **Мікрофону потрібен https.** Відкриття `index.html` з локального сховища на телефоні не спрацює — використовуйте URL-адресу GitHub Pages. Тепер застосунок явно повідомляє про це, якщо виявляє незахищений контекст.
- **На iOS кожен браузер — це Safari під капотом**, тож правила Safari застосовуються всюди. Звук запускається лише після дотику (кнопки відтворення це враховують), а фізичний перемикач беззвучного режиму може заглушити відтворення.
- **Перехід застосунку у фоновий режим** зупиняє поточний запис; застосунок виявляє це й акуратно перериває процес замість оцінювання шуму.
- Визначення висоти звуку обмежено приблизно до 30 Гц, щоб зберегти прийнятне навантаження на процесор телефонів.

## Звук: тон проти фортепіано

**Чистий тон** генерується осцилятором Web Audio і повністю працює офлайн.

**Фортепіано** використовує реальні записані семпли, із трирівневим резервним механізмом, щоб працювати в будь-якій ситуації:

1. **Локальні семпли** — якщо `samples/piano/` присутній у репозиторії, фортепіано відтворюється з вашої власної копії без зовнішньої залежності. Семпли завантажуються окремо в міру відтворення нот, а не одним пакетом.
2. **CDN** — якщо локальних семплів немає, але ви онлайн, завантажується фортепіано через [smplr](https://github.com/danigb/smplr).
3. **Синтезований тон** — якщо жоден варіант недоступний (наприклад, `index.html` відкрито окремо, офлайн), застосунок повертається до вбудованого синтезованого тону.

### Додавання локальних семплів фортепіано

Застосунок очікує семпли **Salamander Grand Piano V3** у форматі MP3, шар гучності 8, у `samples/piano/`:

```bash
npm install @audio-samples/piano-mp3-velocity8
# copy node_modules/@audio-samples/piano-mp3-velocity8/audio/*.mp3 into samples/piano/
```

Назви файлів відповідають шаблону `C4v8.mp3`, `D#4v8.mp3`, `A2v8.mp3` — назва ноти, потім суфікс гучності `v8`. Salamander семпльований з інтервалом мала терція (C, D#, F#, A кожної октави), і застосунок зсуває висоту щонайбільше на один півтон, щоб заповнити прогалини, що на практиці непомітно на слух. Для покриття діапазону застосунку E2–C6 потрібно лише 16 файлів.

Ці семпли є стороннім контентом — див. [NOTICES.md](NOTICES.md).


## Запуск локально

Просто відкрийте `index.html` у браузері — або, оскільки мікрофонам у деяких браузерах потрібен захищений контекст, обслуговуйте його через сервер:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Розгортання на GitHub Pages

1. Створіть новий репозиторій і завантажте ці файли:

   ```bash
   git init
   git add .
   git commit -m "Pitch trainer"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/pitch-trainer.git
   git push -u origin main
   ```

2. У репозиторії перейдіть до **Settings → Pages**.
3. У розділі **Build and deployment** встановіть **Source** на *Deploy from a branch*, оберіть **main** / **`/root`** і збережіть.
4. За хвилину ваш інструмент буде доступний за адресою `https://YOUR-USERNAME.github.io/pitch-trainer/`.

GitHub Pages обслуговує через HTTPS, що необхідно для доступу до мікрофона — тож розгорнута версія завжди зможе запитати доступ до мікрофона.

## Примітки та обмеження

- Визначення висоти звуку використовує **автокореляцію**, яка не потребує залежностей і добре працює для чистих сталих нот, але може «плавати» на диханні або сильному вібрато. Для надійнішого визначення можна підключити [pitchy](https://github.com/ianprime0509/pitchy) (метод McLeod) або CREPE.
- Розділення нот у режимі «Слідуй за мною» працює за евристикою — дуже плавні (легато) фрази (без паузи між нотами) або сильне вібрато можуть іноді неправильно об'єднати чи розділити ноту.
- Працює в будь-якому сучасному браузері. Потребує дозволу на використання мікрофона.
